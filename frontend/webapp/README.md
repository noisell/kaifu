# KAIFU — Telegram Mini App

Я разработал пользовательское приложение KAIFU на Next.js, React и TypeScript. Оно работает внутри Telegram и объединяет игровые билеты, задания, реферальную программу, профиль и TON-кошелёк.

Пользователь входит через Telegram, видит призовой фонд, приобретает билеты и управляет их номерами и активацией. В профиле доступны внутренние балансы и история операций. Для приглашений я реализовал персональные ссылки и список друзей, для заданий — отдельные экраны и взаимодействие с API.

TON Connect отвечает за подключение кошелька и запрос подписи транзакции. Покупка через Stars использует Telegram invoice. Интерфейс поддерживает русский и английский языки, BackButton, popup-уведомления и тактильную обратную связь Telegram.

**Стек:** Next.js 14.0.1, React 18, TypeScript, Tailwind CSS, Ant Design, Axios, Telegram WebApp SDK, TON Connect.

## Структура экранов

| Маршрут | Содержание |
| --- | --- |
| `/` | Вход, первый запуск, призовой фонд и покупка билетов |
| `/tickets` | Билеты, номера, активация и выигрыши |
| `/friends` | Реферальная ссылка и приглашённые пользователи |
| `/tasks` | Задания и их выполнение |
| `/profile` | Балансы, кошелёк, пополнение, заявки на вывод и история |
| `/settings` | Выбор языка |

## Локальный запуск

Из директории `frontend/webapp`:

```bash
npm ci
# Создайте .env.local по .env.example и укажите адрес API и ссылки тестового бота.
npm run dev -- --port 3000
```

Для production-сборки:

```bash
npm run build
npm run start -- --port 3000
```

Я проверил установку и сборку на Node.js 24.22.1. Зависимости зафиксированы в `package-lock.json`. Публичные параметры `NEXT_PUBLIC_*` встраиваются при сборке; секреты в них хранить нельзя.

## Настройка интеграций

Mini App ожидает контекст `Telegram.WebApp`. Для проверки входа нужен HTTPS-адрес, подключённый к тестовому боту; автономного demo-режима в этой версии нет.

Перед собственным развёртыванием необходимо настроить TON Connect manifest в `src/app/layout.tsx` и `public/tonconnect-manifest.json`, а также заменить или удалить исторический счётчик Яндекс Метрики. Подтверждение платежа и изменение баланса должны обеспечиваться сервером.
