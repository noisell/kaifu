# KAIFU · Telegram Mini App

Я разработал пользовательскую часть [KAIFU](../../README.md): мобильный интерфейс внутри Telegram с билетами, призовым фондом, заданиями, реферальной программой и TON-кошельком.

**Стек:** Next.js 14.0.1, React 18, TypeScript, Tailwind CSS, Ant Design, Axios, Telegram WebApp SDK, TON Connect.

## Разделы

| Маршрут | Назначение |
| --- | --- |
| `/` | Авторизация через Telegram, первый запуск, призовой фонд, покупка билетов |
| `/tickets` | Билеты, номера, активация и выигрыши |
| `/friends` | Реферальная ссылка и приглашённые пользователи |
| `/tasks` | Задания и проверка их выполнения через API |
| `/profile` | Балансы, TON-кошелёк, пополнение, заявка на вывод и история |
| `/settings` | Переключение русского и английского языка |

## Запуск

Из этой директории, с установленным Node.js и npm:

```bash
npm ci
# Скопируйте .env.example в .env.local, не перезаписывая существующие настройки.
# Укажите адрес совместимого API и ссылки тестового бота/каналов.
npm run dev -- --port 3000
```

Production-сборка: `npm run build`, запуск после сборки: `npm run start -- --port 3000`. Установка и сборка проверяются по сохранённому `package-lock.json`; результаты текущей проверки — в [статусе проекта](../../docs/STATUS.md). Версия Node.js в исходниках не закреплена; я выполнял проверку на Node.js 24.22.1.

Все `NEXT_PUBLIC_*`-переменные доступны браузеру и встраиваются при сборке. Изменение адреса API после `npm run build` требует новой сборки. Секреты в эти переменные помещать нельзя.

## Интеграции и ограничения

- Главная страница ожидает `Telegram.WebApp` и пользователя из Telegram. Автономного demo-режима и фиктивной авторизации нет.
- Для проверки внутри Telegram нужен HTTPS-адрес приложения, настроенный у отдельного тестового бота.
- Адрес TON Connect manifest задан в `src/app/layout.tsx`; исторические домены также есть в `public/tonconnect-manifest.json`. Они не подтверждены как действующие. Для собственного развёртывания нужны свои адреса.
- В layout остался счётчик Яндекс Метрики исторического проекта. Перед собственным публичным запуском замените или удалите интеграцию в рамках отдельной настройки.
- TON Connect вызывает запрос подписи транзакции в кошельке. Наличие обработчика в UI не подтверждает серверную проверку платежа и начисления.
- Восстановленный Python backend содержит API билетов, заданий, рефералов и истории. Состояние миграций, обработки Stars и подтверждения TON-платежей описано в [техническом статусе](../../docs/STATUS.md); сквозная проверка финансовых сценариев не выполнялась.
