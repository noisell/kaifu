# KAIFU — fullstack-кейс

## Проект

**KAIFU** — Telegram Mini App, который я разработал для заказчика с игровой механикой, билетами, заданиями, реферальной программой и TON-кошельком. Отдельная браузерная админ-панель предназначена для работы с пользователями, балансами, транзакциями, статистикой и настройками экономики.

**Моя роль:** я был единственным fullstack-разработчиком. Самостоятельно разработал Mini App, панель оператора, backend, Telegram-бота, схему PostgreSQL и фоновую обработку.

**Эксплуатация:** проект запускался с реальными пользователями; аудитория — около **10 000 человек** по моим данным. Это моя оценка аудитории, а не показатель одновременной нагрузки.

## Инженерные решения

**Два интерфейса для разных задач.** Я разделил пользовательские и операторские сценарии. Пользователю нужен мобильный интерфейс внутри Telegram; оператору — плотные таблицы, фильтры, графики и формы. Поэтому я реализовал Mini App и админ-панель отдельными Next.js-приложениями с общим backend.

**Разделение API и доступа к данным.** Маршруты обрабатывают HTTP, сервисы описывают сценарии, репозитории выполняют SQL, а Unit of Work управляет сессиями и явными транзакциями. Это позволяет использовать сервисы и из HTTP, и из фонового consumer.

**Фоновый контур розыгрышей.** Планирование вынесено в Celery Beat, передача работы — в очередь, обработка — в отдельный процесс. HTTP API не является точкой запуска ежедневного расписания.

**Интеграция с Telegram.** initData передаётся с клиента и проверяется сервером; интерфейс использует Telegram BackButton, popup, haptic feedback и invoice flow.

## Подтверждённая проверка публичного среза

Я проверил production-сборку обоих frontend-приложений, запустил обновлённый backend с PostgreSQL и Redis и выполнил 15 успешных групп ручных проверок, включая профили/JWT, аватар, рефералов, покупку серебряного билета, списание и административное изменение баланса.

Исторический срез содержит незавершённые части: расхождения миграции с моделями, финальную ветку jackpot и подтверждение checkout для оплаты Stars. Финансовые интеграции и права на операции требуют отдельного укрепления перед новым публичным запуском. Полный перечень — в [STATUS.md](STATUS.md).
