# KAIFU — панель управления

Для оператора KAIFU я разработал отдельное веб-приложение на Next.js и TypeScript. Панель объединяет статистику проекта, работу с пользователями, билетами и денежными операциями, управление банком и параметрами экономики.

Я использовал Ant Design для таблиц, поиска, сортировки и форм редактирования, а Recharts — для графиков. Вход и обновление сессии работают через административный API; сервер проверяет уровень доступа. Для обработки TON-выплат в интерфейс подключён TON Connect.

**Стек:** Next.js 14.1.4, React 18, TypeScript, Ant Design, Recharts, Axios, TON Connect.

## Разделы

| Маршрут | Содержание |
| --- | --- |
| `/` | Вход и статистика |
| `/users` | Пользователи, балансы и блокировки |
| `/transactions` | Денежные операции и интерфейс выплат |
| `/bank` | Параметры банка |
| `/tickets` | Билеты |
| `/wins` | Выигрыши и статусы получения |
| `/jackpot` | Ежедневные результаты и управление jackpot |
| `/settings` | Настройки экономики |

## Локальный запуск

Из директории `frontend/admin`:

```bash
npm ci
# Создайте .env.local по .env.example и укажите NEXT_PUBLIC_API_URL.
npm run dev -- --port 3001
```

Для production-сборки:

```bash
npm run build
npm run start -- --port 3001
```

Я проверил установку и сборку на Node.js 24.22.1. Порт 3001 позволяет запускать панель одновременно с Mini App. `NEXT_PUBLIC_API_URL` встраивается в браузерный код при сборке; пароли, токены и приватные ключи в frontend-конфигурацию добавлять нельзя.

## Подключение к серверу

Панель использует `/auth/admin/login` и группы `/admin/stats`, `/admin/user`, `/admin/money`, `/admin/bank`, `/admin/lottery`, `/admin/system`. Я проверил чтение административных данных и изменение баланса с локальным admin JWT. Браузерный вход, refresh-cookie и реальные выплаты требуют отдельной проверки.

Для собственного запуска необходимо настроить TON Connect manifest в `src/app/layout.tsx` и согласовать origin панели с CORS-конфигурацией API. Проверка прав выполняется на сервере.
