# KAIFU — проект для портфолио

Я самостоятельно разработал KAIFU для заказчика: Telegram Mini App, веб-панель администратора, асинхронный backend, Telegram-бота и фоновую обработку розыгрышей. Аудитория проекта составляла **10 000 пользователей**.

В пользовательском приложении я реализовал сценарии билетов, заданий, рефералов и работы с TON-кошельком. Для оператора разработал панель со статистикой, таблицами пользователей и операций, редактированием балансов и настройками экономики.

Клиентские приложения построены на Next.js, React и TypeScript. Серверная часть использует FastAPI, PostgreSQL и асинхронный SQLAlchemy. Я разделил обработчики, сервисы и репозитории, применил Unit of Work для управления сессиями и транзакциями. Фоновые задачи организовал с помощью Celery, Redis и RabbitMQ.
